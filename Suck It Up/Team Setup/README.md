# Team plugin setup

The vault's notes and attachments sync through EVC Team Relay. Obsidian keeps community plugins in its hidden `.obsidian` folder, which Relay does not expose as ordinary vault content.

On a new Windows computer:

1. Let the `Suck It Up` share finish its first sync.
2. Close Obsidian.
3. Double-click `Install Team Plugins.cmd` in this folder.
4. Reopen the vault.

This installs the shared QuickAdd, Note Toolbar, Modal Forms, and Excalidraw versions and settings. It does not replace EVC Team Relay or its login/server configuration.
